# Dias e Pacheco Detailing

Landing page estática, construída de raiz em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `styles.css` — identidade visual e comportamento responsivo
- `main.js` — vídeos, menu, acordions e animações
- `assets/video/` — versões MP4 H.264 sem áudio
- `assets/posters/` — frames extraídos dos próprios vídeos
- `netlify.toml` — configuração de publicação
- `robots.txt` — proteção da demonstração contra indexação

## Publicar na Netlify

1. Extraia o ZIP.
2. Coloque os ficheiros e pastas na raiz do repositório GitHub.
3. Ligue o repositório à Netlify sem comando de build; a pasta de publicação é `.`.

## Antes do lançamento público

O projeto está configurado como demonstração privada com `noindex` e `Disallow: /`. Remova estas restrições apenas quando existir autorização para indexação pública.
