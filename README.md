# Dias e Pacheco Detailing

Landing page estática para a Dias e Pacheco Detailing, preparada para GitHub e Netlify.

## Estrutura

- `index.html` — conteúdo e estrutura
- `styles.css` — identidade visual e comportamento responsivo
- `main.js` — preloader, navegação, vídeo, accordions e animações
- `assets/video/` — os dois vídeos fornecidos
- `netlify.toml` — configuração de publicação
- `robots.txt` — proteção da demonstração contra indexação

## Publicar na Netlify

1. Extraia o ZIP.
2. Coloque o conteúdo desta pasta na raiz do repositório GitHub.
3. Na Netlify, ligue o repositório sem comando de build; a pasta de publicação é `.`.

## Antes do lançamento público

O projeto está configurado como demonstração privada com `noindex` e `Disallow: /`. Remova essas restrições quando existir autorização para indexação pública.

Os contactos e a disponibilidade devem ser confirmados diretamente com o negócio.
